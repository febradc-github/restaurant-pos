# C-34: Owner Console Session Bar Contrast & Sidebar Label Truncation

Two rendering bugs in the Owner Console shell. (1) The "Logged in as {name} ({role})" session-bar text is unreadable when the OS is in dark mode -- leftover pre-C-29 landing-page CSS in `frontend/src/index.css` paints the page background near-black via `@media (prefers-color-scheme: dark)`, and `.app__session` (`frontend/src/App.css`) has no background of its own to shield it, so antd's light-theme dark text renders dark-on-dark. (2) The sidebar's "Menu Management" nav label truncates to "Menu Manage..." because `OwnerPage.tsx`'s `Layout.Sider` uses antd's default 200px width while this app's `theme.ts` sets `fontSize: 16` (vs antd's 14px baseline that 200px assumes), so the label no longer fits and antd's built-in menu-item ellipsis kicks in.

## Acceptance criteria
- Session-bar text is legible with adequate contrast regardless of OS color-scheme preference (light and dark)
- "Menu Management" and all other Owner Console nav labels render in full, untruncated, with the sidebar expanded; collapsed-sidebar behavior unchanged
- Existing frontend tests still pass, `tsc -b` clean, oxlint clean
