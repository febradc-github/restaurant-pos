# C-27: Demo Data Seeder

Replaces the default `DatabaseSeeder` stub with a full demo dataset covering every role and screen in the app: one Owner, one Cashier, one Server, and two Kitchen users with fixed, documented credentials; a realistic menu; inventory items with a deliberate restock shortfall; tables; and a spread of sample orders (with resulting time_entries) so the Owner Analytics Dashboard, Kitchen Display, and Cashier Checkout all show meaningful data out of the box.

## Acceptance criteria
- Running `php artisan db:seed` populates one Owner, one Cashier, one Server, and two Kitchen users, all `active`, with fixed and documented credentials (email+password for login roles, a 6-digit PIN for each Kitchen user).
- Seeds a realistic menu (multiple categories, multiple items with prices) and inventory items (with `stock` and `threshold` set so at least one ingredient shows a restock shortfall).
- Seeds tables and a spread of sample orders across the last 30 days with a mix of statuses (several `Paid`, dated via `paid_at`, so the Analytics Dashboard's sales/best-seller views show non-empty data) plus resulting `time_entries` for the seeded Server/Cashier/Kitchen users.
- All seeded credentials are printed to console output when the seeder runs, so they're easy to find without reading the seeder source.
