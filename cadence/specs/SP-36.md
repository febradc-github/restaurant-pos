# C-36: App-Wide Dark Theme Foundation -- Spec

## Acceptance criteria
- [ ] `theme.ts`'s `ConfigProvider` uses a dark palette (dark algorithm + dark neutral tokens) with the existing terracotta `#C2410C`-family color retained as `colorPrimary`
- [ ] `index.css`'s leftover `@media (prefers-color-scheme: dark)` block is removed or reconciled so it no longer fights the app's own theme
- [ ] C-34's session-bar background fix (`App.tsx` `SessionBar`) re-verified under the new theme; simplified if now unnecessary, left as-is with a note if still needed
- [ ] Every existing route (Login, Owner Console, Cashier, Take-Orders, Kitchen) renders with adequate text/background contrast under the new theme -- no dark-on-dark or light-on-light regressions
- [ ] All existing frontend tests pass under the new theme; `tsc -b` clean, oxlint clean

## Out of scope
- Any page layout or interaction changes (those belong to C-37/C-38/C-39)
- Mobile/tablet responsiveness work (handled per-page in C-37/C-38/C-39)
