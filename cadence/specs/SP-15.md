# C-15: Foundation: Routing, Ant Design & Brand Theme -- Spec

## Acceptance criteria
- [ ] `react-router-dom` and `antd` are added as dependencies.
- [ ] Routes exist for `/login`, `/owner`, `/cashier`, `/take-orders`, `/kitchen`.
- [ ] Owner and Cashier routes are gated behind login exactly as today; Take-Orders is gated behind login exactly as C-11 established; Kitchen's route is reachable with no login required (explicit regression check against adr-008-server-login-kitchen-pin-attendance).
- [ ] A single shared `ConfigProvider` theme (custom brand color palette + typography, chosen via `ui-ux-pro-max`) is established and applied at the app root.
- [ ] `Login.tsx` is rebuilt using Ant Design components, preserving existing login behavior (identifier + password, error display on failure).
- [ ] No backend changes; existing `/api/login` contract is unchanged.

## Out of scope
Per-page layout/navigation decisions for Owner/Cashier/Take-Orders/Kitchen -- those belong to [[US-16]], [[US-17]], [[US-18]], [[US-19]], each invoking `ui-ux-pro-max` for their own page within the theme this story establishes.
