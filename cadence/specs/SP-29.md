# C-29: App Shell Regression Fix -- Spec

## Acceptance criteria
- [ ] `place-items: center` and all other dead Vite-starter CSS/markup
      (`.hero`, `#next-steps`, `#docs`, `#spacer`, `.framework`, `.vite`,
      `.base`, `#root`'s `width: 1126px` landing constraint) are removed
      from `frontend/src/App.tsx` and `frontend/src/App.css`.
- [ ] Every routed page (Login, Owner Console, Cashier, Take-Orders,
      Kitchen) renders at full available width with no shrink-to-fit
      collapse; the Owner Table Layout page's "Floor Plan" heading and
      800x600 canvas render normally.
- [ ] Login's centered appearance is preserved (no visual regression).
- [ ] The full frontend test suite passes with no regressions.

## Out of scope
Per-page design polish/consistency audits -- those are [[US-30]] through
[[US-33]]. This item only fixes the app-shell collapse bug and removes dead
CSS/markup.
