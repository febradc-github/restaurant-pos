# C-31: Owner Console UI Audit & Fixes -- Spec

## Acceptance criteria
- [ ] The shared `OwnerPage` shell (Sider, Header, nav) and all four
      sections (Table Layout, Menu Management, Employees, Analytics) are
      audited against `ui-ux-pro-max` guidelines: accessibility,
      spacing/typography consistency, Ant Design token usage, visual
      polish.
- [ ] All concrete findings from the audit are fixed, or explicitly logged
      in this item's notes as an out-of-scope follow-up with a stated
      reason.
- [ ] The Table Layout page's "Floor Plan" heading and 800x600 canvas are
      confirmed rendering correctly (the epic's origin bug, re-verified
      here, after [[US-29]]'s shell fix).
- [ ] The full frontend test suite passes with no regressions across all
      four Owner Console sections.

## Out of scope
The app shell itself ([[US-29]]) and any other page's audit.
