# C-37: Owner Console Table Layout Rebuild (Zone Card Grid) -- Spec

## Acceptance criteria
- [ ] `tables` gains a persisted `zone` column (migration + model + validation + API resource output); existing table CRUD endpoints accept/return it
- [ ] `TableLayoutEditor`'s canvas is replaced by a card-grid component: stat row (Tables/Seats/Occupied), inline Add-table form (including Zone), color-coded rounded table cards grouped by zone heading. **Amended during implementation**: ships with two states -- green (available) / red (occupied, derived from whether the table has an open order in Pending/Ready status) -- not three. "Reserved" (orange) has no backing data model anywhere in this system (no reservations feature exists at all) and the user decided during implementation that it warrants a full booking system (customer details, date/time, party size, a reservations list UI, auto-expiry, conversion-to-order), which is materially bigger than this spec's original scope. That's tracked separately as a future, not-yet-created story under [[EP-35]] (its id was not reserved -- C-40 has since been used for an unrelated task, so the reservation story will get whatever id is next when it's actually refined/spec'd); C-37 ships now with two states and the legend/UI accommodates a third color being wired in later without rework.
- [ ] Selecting a table shows a right-hand detail panel with its shape/seats/zone/server and Edit/Duplicate/Remove actions
- [ ] Table edit form includes a Zone field; existing shape/capacity fields preserved
- [ ] Menu Management, Employees, and Analytics pages visually match the new dark theme (from C-36); their existing layouts and interactions are otherwise unchanged
- [ ] Owner Console's sidebar collapses to a drawer/toggle pattern on tablet-width viewports; desktop expand/collapse behavior (C-31/C-34) unchanged
- [ ] Existing `OwnerPage.test.tsx`/`TableLayoutEditor.test.tsx` coverage updated for the new component; new tests cover zone grouping, card color-coding by status, and detail-panel actions
- [ ] `tsc -b` clean, oxlint clean; backend tests pass, Pint clean

## Out of scope
- Free-form (x/y) table positioning -- deliberately removed with the canvas; card order within a zone is the new arrangement mechanism
- Any change to Menu Management/Employees/Analytics beyond visual dark-theme alignment (no layout/interaction rework of those three pages)
