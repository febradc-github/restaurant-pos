# C-30: Login Page UI Audit & Fixes -- Spec

## Acceptance criteria
- [ ] Login screen audited against `ui-ux-pro-max` guidelines: accessibility
      (contrast ratios, focus states, keyboard navigation, touch target
      sizes), typography/spacing consistency, and Ant Design token usage.
- [ ] All concrete findings from the audit are fixed, or explicitly logged
      in this item's notes as an out-of-scope follow-up with a stated
      reason.
- [ ] The full frontend test suite passes with no regressions on Login.

## Out of scope
The app shell itself ([[US-29]]) and any other page's audit.

See [[DS-30]] for rationale and trade-offs.
