# C-24: Sales & Best-Seller Analytics API -- Spec

## Acceptance criteria
- [ ] Owner-gated endpoint returns revenue grouped by day for Paid orders within a given date range, dated by `paid_at`.
- [ ] Owner-gated endpoint returns menu items ranked by quantity sold and by revenue (both metrics present per item) for Paid orders within a given date range.
- [ ] Cancelled, Pending, and Ready orders are excluded from both endpoints -- only `Paid` orders contribute.
- [ ] Query logic uses `Order` local scopes (chainable, mirroring `TimeEntry`'s pattern) rather than one-off raw SQL.
- [ ] Both endpoints are covered by tests using real mutation/query checks (seeded orders of varying status, confirming exclusion of non-Paid orders and correct ranking/grouping).

## Out of scope
The inventory restock endpoint ([[US-25]]) and the dashboard UI consuming this API ([[US-26]]).
