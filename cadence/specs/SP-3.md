# C-3: Table Layout Editor -- Spec

## Acceptance criteria
- [ ] Owner can access a drag-and-drop canvas representing the restaurant floor.
- [ ] Owner can add, move, resize, and delete tables on the canvas.
- [ ] Tables support different shapes (e.g. round, square, rectangular) and configurable seat capacity.
- [ ] The layout persists and reloads correctly (survives a page refresh or server restart).
- [ ] Non-Owner roles cannot edit the layout.

## Out of scope
- Multiple floors/sections (single floor plan only, per brainstorm).
- Table merging/splitting for large parties (not requested).
