# C-17: Cashier Page -- Design

## Parent
Part of [[EP-14]] -- see [[DS-14]] for the umbrella rationale. Depends on [[US-15]] (routing + shared theme) landing first.

## Problem
`Checkout` is currently rendered inline in `App.tsx` for a logged-in Cashier, styled ad-hoc and disconnected from the rest of the redesign.

## Approach
Build `CashierPage` at the `/cashier` route (established in C-15). Invoke `ui-ux-pro-max` for this page's layout within the C-15 shared theme. Fully rebuild `Checkout` (payment method selection, payment confirmation, print-failure vs. success distinction, cancel) with Ant Design components.

## Acceptance criteria
- `CashierPage` exists at `/cashier`, gated behind login as today (login = time-in per C-11), using the C-15 shared theme.
- `Checkout` is fully rebuilt with Ant Design components, preserving existing payment-method selection, payment confirmation, print-failure-surfaced-distinctly-from-success behavior, and order cancellation (C-7).
- Cashier-only gating (both UI visibility and existing API authorization) is unchanged.
