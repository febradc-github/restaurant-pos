# C-29: App Shell Regression Fix -- Design

## Parent
Part of [[EP-28]] -- see [[DS-28]] for the umbrella rationale.

## Problem
`frontend/src/App.tsx` wraps every route in `<main id="center">`, and
`App.css`'s `#center` rule carries a leftover `create-vite`-starter-template
`place-items: center` declaration, forcing every routed page's root element to
shrink-to-fit instead of stretch to fill available width. This cascades into
collapsed/garbled layout -- confirmed via a user screenshot showing the Owner
Table Layout page's "Floor Plan" heading rendered one character per line, plus
a stray misplaced element. `App.css` also carries other dead starter CSS
(`.hero`, `#next-steps`, `#docs`, `#spacer`, `.framework`, `.vite`, `.base`)
and `#root`'s landing-page-oriented `width: 1126px` constraint, none of which
is used by any real POS page.

## Approach
Remove the dead Vite-starter CSS and markup from `App.tsx`/`App.css`, keeping
only what's actually used (`.app__session`, used by `App.tsx`'s `SessionBar`).
Replace `<main id="center">` with a shell wrapper that lets routed pages
stretch to full width. Verify `Login`'s centered appearance survives (it has
its own `Login.css` and appears self-contained, but must be confirmed rather
than assumed). Verify the original reproduction case -- Owner Table Layout
page -- renders correctly after the fix.

## Acceptance criteria
- `place-items: center` and all other dead Vite-starter CSS/markup
  (`.hero`, `#next-steps`, `#docs`, `#spacer`, `.framework`, `.vite`, `.base`,
  `#root`'s `width: 1126px` landing constraint) are removed from
  `frontend/src/App.tsx` and `frontend/src/App.css`.
- Every routed page (Login, Owner Console, Cashier, Take-Orders, Kitchen)
  renders at full available width with no shrink-to-fit collapse; the Owner
  Table Layout page's "Floor Plan" heading and 800x600 canvas render normally
  (the original reported bug is fixed and reproducible-no-more).
- Login's centered appearance is preserved (no visual regression).
- The full frontend test suite passes with no regressions.
