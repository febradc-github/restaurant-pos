# C-18: Take-Orders Page -- Design

## Parent
Part of [[EP-14]] -- see [[DS-14]] for the umbrella rationale. Depends on [[US-15]] (routing + shared theme) landing first.

## Problem
`OrderTaking` is currently rendered inline in `App.tsx`, gated behind login since C-11, but styled ad-hoc and disconnected from the rest of the redesign.

## Approach
Build `TakeOrdersPage` at the `/take-orders` route (established in C-15). Invoke `ui-ux-pro-max` for this page's layout within the C-15 shared theme. Fully rebuild `OrderTaking` (table/item selection, order submission) with Ant Design components.

## Acceptance criteria
- `TakeOrdersPage` exists at `/take-orders`, gated behind login exactly as C-11 established (login = time-in, logout = time-out), using the C-15 shared theme.
- `OrderTaking` is fully rebuilt with Ant Design components, preserving existing table/item selection and order-submission behavior (C-6).
- Server-only gating (both UI visibility and existing API behavior) is unchanged.
