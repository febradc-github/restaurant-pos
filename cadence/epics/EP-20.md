# C-20: Owner Employee Management

Gives the Owner a real, in-app way to register employees (name, role, and role-appropriate credential -- password for Owner/Cashier/Server, PIN for Kitchen), change their role, and deactivate/reactivate them, instead of the current state where every User only exists via test factories. Deactivation never deletes historical time_entries/orders. Lands as a new "Employees" section in OwnerPage's nav shell.
