# C-1: Restaurant POS System

A custom-built, self-hosted point-of-sale system for a single restaurant in the Philippines, covering order-taking, owner-configurable table layout, menu management, inventory tracking, role-based access (Owner/Cashier/Server/Kitchen), and manual payment confirmation (cash/QR Ph/GCash) with receipt and cash-drawer hardware integration -- all deployed on-premise with no cloud dependency.
