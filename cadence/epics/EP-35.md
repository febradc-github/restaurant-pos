# C-35: Dark Theme Redesign & UX Overhaul (Owner Console, Cashier, Server)

Replaces the app's light terracotta Ant Design theme with an app-wide dark theme (keeping the terracotta/orange accent), and overhauls three role screens' interaction models per user-supplied reference designs: Owner Console's Table Layout moves from a drag/resize canvas to a zone-grouped color-coded card grid (with a new persisted table `zone` field); Cashier/Checkout gains order identity/elapsed time, per-line prices, truncation for long orders, a shift-summary header, and search/sort; Server/Take-Orders gains compact item cards, category-grouped menu with filters, chip-based table selection, and a persistent order-summary panel with a new persisted kitchen-notes field. All three pages (plus the Owner Console shell) must remain usable at tablet width.
