# C-37: Owner Console Table Layout Rebuild (Zone Card Grid)

Replaces `TableLayoutEditor`'s canvas-based drag/resize floor-plan editor with a zone-grouped, color-coded table card grid (stat row, add-table form, detail panel), backed by a new persisted `zone` field on `Table`. Menu Management, Employees, and Analytics get a dark-theme visual pass only. Owner Console's sidebar becomes tablet-responsive. Depends on [[US-36]].
