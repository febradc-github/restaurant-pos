# C-24: Sales & Best-Seller Analytics API

Adds Order-model chainable scopes (mirroring TimeEntry's pattern) and Owner-gated endpoints for sales-over-time (revenue by day) and best/worst-selling menu items (quantity and revenue), computed only from Paid orders dated by paid_at.
