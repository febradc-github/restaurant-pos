# C-36: App-Wide Dark Theme Foundation

Switches the app's single global antd `ConfigProvider` from its light palette to a dark palette, keeping the existing terracotta accent color, and reconciles `index.css`'s leftover pre-C-29 dark-mode CSS and the C-34 session-bar fix against the new theme. Foundation story for C-35's page redesigns (C-37/C-38/C-39), which assume a dark theme is already in place.
