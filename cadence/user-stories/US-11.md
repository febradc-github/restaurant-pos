# C-11: Server & Cashier Login-Based Time Tracking

Adds a `time_entries` model and gives Server a real login (mirroring Cashier's existing Sanctum flow), so both roles' login/logout now records clock-in/clock-out. The Take-Orders frontend page is gated behind login the same way Cashier's Checkout page already is.
