# C-21: Employee Management API

Adds an `active` column to `users` and Owner-gated CRUD endpoints (create/list/update/deactivate/reactivate) reusing the existing User model and UserRole enum. Extends AuthController::login and KitchenClockController::clock to reject deactivated employees, and blocks self-deactivation and deactivating the last active Owner.
